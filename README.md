# infine

Diamonds and fine jewellery, Dubai. Real diamonds, limited drops: tennis bracelets, tennis necklaces and black diamonds.

This repo hosts the infine website (GitHub Pages) and the launch assets.

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | Holding page for drop 01 (replace with the full website build when ready) |
| `assets/brand/` | Launch Kit and Mural / Crypto / Gen Z brand PDFs |
| `assets/images/` | Cleaned product imagery (bracelet stacks, rings, shapes, custom chain renders) |
| `assets/covers/` | Gen Z story covers (9:16) |
| `assets/video/` | Drop 01 launch films, 60s 9:16 (house and R&B versions) |
| `video-source/` | Source for rebuilding the launch film (HTML engine + build/export scripts) |
| `downloads/infine-launch-kit.zip` | Everything above in one zip |

## Hosting

Settings > Pages > Source: Deploy from a branch > `main` / root. The site will be at `https://punitthakker.github.io/infine/`.
